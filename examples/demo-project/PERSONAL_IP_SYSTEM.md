# 个人 IP 制作与验收系统

## 决策

脚本确认、真实素材与主构图确定后，从三种决策中选择一种，同时写入 `storyboard.md` 与 `publish-package.json`：

| 决策 | 使用条件 |
| --- | --- |
| `omitted` | 没有明确叙事职责；题材严肃；会遮挡证据 |
| `static` | 一个姿势足以指向、比较或承接提问 |
| `used` | 动作能把一项事实变成可见关系 |

默认不是 `used`。一般一条视频只安排 1—2 次短时出现，每次约 2—4 秒。

动作必须记录：触发事实、动作任务、可见结果、落定状态、退出方式。
