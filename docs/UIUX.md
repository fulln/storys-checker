# Storys Checker · UI/UX 规范

> 依据 GitHub 主流管理后台 / 监控仪表盘设计模式提炼，统一本面板所有页面。
> 参考：satnaing/shadcn-admin（1.4w★）、Ant Design Pro、Grafana、Netdata。
> 原则：**不平铺**。页面 = 分析行（指标）→ 主工作区 → 辅助区，层级化组织，而非无限向下堆叠。

## 1. 布局系统

- 固定左侧导航（224px）+ 顶栏（60px，项目上下文 + 全局操作）+ 内容区（max 1440px）
- 内容区为 12 列网格；页面区块按优先级分三层：
  1. **分析行**：metric 卡（4 列一排），一眼看总量/状态
  2. **主工作区**：核心交互面板（表格 / 工作台 / 折叠树），占主列
  3. **辅助区**：次要信息两栏并排（`grid-cols-2`），不再各占全宽
- 每页最多 3 个视觉层级，禁止 5+ 个全宽 section 纵向堆叠

## 2. 设计令牌（style.css `:root`）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg / --bg-soft` | `#0d1220 / #10151f` | 页面底色 / 次级底 |
| `--card` | `#151b2b` | 卡片底 |
| `--border / --border-soft` | `#232c42 / #1b2335` | 边框层级 |
| `--text / --muted` | `#e7ecf6 / #8691a8` | 正文 / 弱化 |
| `--accent` | `#4fd1c5` | 进行中 / 主强调 |
| `--green` | `#5eead4` | 成功 / 已完成 |
| `--gold` | `#f4b942` | 警告 |
| `--warm` | `#e85d3f` | 错误 / 未开始 |
| `--purple` | `#a78bfa` | 中性类别 |
| `--radius` | `12px` | 大卡片圆角 |
| `--shadow` | `0 8px 24px rgba(0,0,0,.35)` | 浮层 |

间距用 8px 网格：区块 24px、卡内 12–16px、行内 8px。

## 3. 组件规范

- **Metric 卡** `.metric`：左上小标签 + 大数字 + 右下状态点/变化。hover 轻微提亮 + 边框 accent。
- **面板** `.panel`:标题行（图标 + 标题 + 右侧操作/计数）+ 内容；hover 边框提亮。
- **卡片** `.card`：`border 1px var(--border)` + `--radius`，hover 提亮（`--card-hover`）。
- **徽章** `.badge`：语义色底 + 同色字；类别用固定色（`p`=warm、`comp`=accent、`mine`=green）。
- **状态视觉**：圆点（绿=成功/进行中、灰=未开始、红=失败）+ 徽章 + 进度条统一语义。
- **表格** `.table-wrap`：细边框 + hover 行提亮 + 首列 code 字体。
- **空状态** `.empty`：居中弱化文案 + 可选行动按钮。
- **折叠** `<details>`：门禁/脚本分组用，summary 可点击带箭头。
- **动效**：hover 过渡 0.15s；进度条宽度过渡 0.5s。

## 5. 审美规范（硬性约定）

- **禁止 emoji**（👁✏️💾⚡🔴🟡⚪🎉🚀 等彩色表情一律不用），理由：彩色 emoji 破坏暗色界面的克制感与字体一致性。
- **图标策略**：
  - 侧边导航：几何 / 键盘符号（`▣ ◈ ▤ ✦ ⇶ ⌘ ♫ ✓`），16px 弱化色
  - 操作按钮：纯文本，必要时前缀中性符号（`▶` 运行、`■` 中断、`↻` 刷新）
- **状态视觉**：状态一律用语义色（CSS）表达——圆点、徽章、进度条、文字色；不依赖 emoji 字符。
  - 错误 `--warm` / 警告 `--gold` / 提示 `--muted` / 成功 `--green` / 进行中 `--accent`
- **中性文本符号**允许：`✓ / ✕ / · / ● / ▸`（单色、随字体渲染，用于列表与状态前缀）。
- **光学对齐（optical alignment）**：对齐以视觉为准，不以数学网格为准。
  - 行内小元素（状态圆点、徽章、编号、图标）与文字用**基线/中线**对齐，不用 `line-height` 硬凑；多行文本前的符号用 `align-items: baseline` 或 `flex-start` + 首行微调。
  - 圆形 / 方形小徽标（状态点、步骤编号）视觉居中：flex 容器 `align-items: center` 后，必要时 `translateY` 微调 0.5–1px 抵消字体上下留白。
  - 编号列表（动作步骤）：编号列右对齐、与正文基线对齐，行高与正文一致（如正文 1.6 → 编号行高 1.6）。
  - 表格：文本列左对齐，数值 / 尺寸 / 时间列右对齐；表头与数据同侧对齐。
  - 中文与数字 / 符号混排时，视觉重心对齐而非盒模型对齐。

## 6. 交互

- 顶栏项目选择器 = **全局上下文**，所有页面联动（见 README「可迭代设计」）。
- 流程监控管线 = 阶段选择器，选中阶段联动工作台（文件/命令/编辑）。
- 任何修改类操作（运行命令、保存文件）实时反馈：日志滚动 + 状态徽章。
