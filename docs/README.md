# 规范文档库

本目录存放本面板的公开工具文档，用于部署、发布和 UI/UX 说明。

生产项目的私有规范快照不属于公开发行内容，公开导出器会明确排除它们。

## 文档说明

| 文件 | 作用 |
| --- | --- |
| `UIUX.md` | 本面板 UI/UX 规范 |
| `PUBLISHING.md` | 本仓库发布到公共仓库前的检查清单（占位符、隐私、自检） |
| `DEPLOY.md` | 部署指南：本机 / systemd / launchd / Docker、安全模型、状态管理、反代与排障 |

## 门禁主线（重点优先级）

事实 → 变量唯一 → 第 1 秒/15 秒 → 技术硬门禁 → 平台适配。

每个门禁的「一句话判断、优先级、硬红线」见 `config.json` 的 `stages[].summary / priority / musts`。
